## Afirmações centrais
| Afirmação | Fontes | Status |
|---|---|---|
| Uma referência tem 3 partes: livro, capítulo, versículo (ex.: Jo 3:16) | 2, 3 | ok |
| Os textos originais não tinham capítulos e versículos numerados; foram acrescentados depois (capítulos no início do séc. XIII; versículos a partir de meados do séc. XVI) para facilitar achar | 3, 4 | ok |
| Jesus achou o lugar num rolo (Lc 4:17), sem números | 1 | ok |
| Abreviaturas: Gn, Mt, Jo (João), Jn (Jonas), 1Jo etc. | 2 | ok, com ressalva de variação |
| Livros com número (1 e 2 Samuel, 1 e 2 Reis… 1, 2 e 3 João) → o número faz parte do nome: Jo 3:16 ≠ 1Jo 3:16 | 1, 2 | ok |
| Livros de 1 capítulo (Ob, Fm, 2Jo, 3Jo, Jd) | 1 | ok; o texto diz que "às vezes" se cita só o versículo |
| Uma frase pode atravessar versículos (Lc 4:17-18, conferido na ACF) | 1, 3 | ok |
| O número pode mudar entre Bíblias (hebraica × cristã; Salmos) → conferir o texto, não só o número | 3, 4 | ok |
| Capítulo e versículo = ajuda para achar, não fazem parte do texto original (paratexto) | 3 | ok — o texto **não** diz que seja "inspirado" ou "não inspirado" |

## Divergências / limites
- Abreviaturas variam entre editoras e sites (a tabela lista variantes: Êx/Ex; Sl/Sal; 1Co/1Cor). O curso fixa um padrão (o da tabela) e diz que podem aparecer outras.
- O padrão ":" entre capítulo e versículo e "-" para faixa é o que aparece nas fontes lidas (ex.: "1 Crônicas 5:27-41"; "Gn 39:15" em fonte consultada via busca). Outras formas existem; não faz parte do tópico.

## O que ficou de fora (e por quê)
- Como ler no contexto / interpretar → aula 1.2. Como usar concordância, Bíblia digital, índice remissivo → fora do escopo (nenhuma fonte lida).
- Pontuação mais complexa (vírgula, ponto e vírgula entre referências): **não verificada em fonte lida** → não entra.
- História detalhada da divisão (nomes e datas além do que a fonte 3 diz) → fora.
- Livros deuterocanônicos e sistemas de numeração católico/ortodoxo → fora (1 frase no T218 já cobre).
